# Spring MVC Hibernate User Registration

A web-based user registration and login application developed using Java, Spring MVC, Hibernate, MySQL, JSP, and Apache Tomcat.

## 📌 Project Overview

This project demonstrates the implementation of the MVC (Model-View-Controller) architecture using Spring MVC and Hibernate.

Users can register their details through a registration form and the application stores the information in a MySQL database using Hibernate ORM.

## 🚀 Features

- User Registration
- User Login
- Form handling using Spring MVC
- Database connectivity using Hibernate
- CRUD operations
- MySQL database integration
- JSP-based user interface
- MVC architecture
- Server-side application using Apache Tomcat

## 🛠️ Technologies Used

- Java
- Spring MVC
- Hibernate ORM
- MySQL
- JSP
- HTML
- Apache Tomcat
- Eclipse IDE
